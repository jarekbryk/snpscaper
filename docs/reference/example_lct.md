# Example data: the LCT region

A `snpscape` object for the lactase gene (LCT) plus 25 kb on each side,
fetched with `fetch_region("LCT")`. It is included so that examples and
tutorials work without an internet connection.

## Usage

``` r
example_lct
```

## Format

A `snpscape` object (see
[snpscape](https://jarekbryk.github.io/snpscaper/reference/snpscape.md)).

## Source

1000 Genomes Project high-coverage phased panel. Built by
`data-raw/examples.R`.

## Examples

``` r
example_lct
#> <snpscape> 2,504 people x 1,922 SNPs (GRCh38)
#> Regions:     LCT (chr2:135,762,850-135,862,184) 
#> Populations: 26 populations in 5 super-populations
#> Steps:       fetched 
```
